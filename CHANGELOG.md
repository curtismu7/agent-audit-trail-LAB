# Changelog

## 0.2.0 (unreleased): moved to a -LAB repo

- Brought to the -LAB standard without new features. Node 26 only (engines, `.nvmrc`, `node:26-alpine`), GitHub-hosted CI (build, test, doctor, forbidden-strings, gitleaks), the shared stylesheet vendored byte-for-byte with app CSS on tokens, a Mock | Live toggle in the header on every page (Live is refused with an honest message), presenter mode on the `P` key, the diagram as diagram-studio/1 data loaded by name, a runtime netguard with a self-test that includes UDP connect, settings only from the shared `~/Development/.env`, a talk track generated from data with a drift test, a README per the README standard, `aria-disabled` Run buttons. Removed: the SE k8s manifests and deploy script, the hosted banner variant, `MODE`, the per-app `.env` loader.
- Fix pass after review. The presenter-mode typing guard is now pinned by one key at a time (vitest and a real-key e2e step; removing the guard fails both). `npm run e2e` no longer reads a file outside the repo: the diagram overlap helper is vendored as `scripts/diagram-overlap.js`, and a test rejects absolute home paths in shipped scripts. The Scenario and Cast selects stay inside their card at 375px (and at 320px there is no page scroll); pinned by an e2e check. The e2e job is back in CI (Playwright Chromium on a hosted runner; `mutation-check` stays by hand).
